# ARENA v3 · Agentes autónomos de cálculo

Abre `index.html` en cualquier navegador (no necesita servidor ni conexión).

Secciones: Matemáticas, Física y Aeroespacial. 10 tipos de problema, más de 60 agentes
(cooperativos 🤝 o solitarios 🐺) que compiten, se detienen al resolver y se recompensan con energía.

Archivos
- js/arena.js        motor: parser, agentes base, competencia, micro pruebas, evolución
- js/agents-plus.js  agentes extra (Tanh-Sinh, PSO, Dormand-Prince, Wynn ε, Yoshida...), órbitas y presets
- js/plot.js         gráficas, iterados en vivo y convergencia
- js/ui.js           secciones, conceptos, ranking, calculadora orbital
- css/style.css      estilos
